# assets/

Ruwe bestanden die Godot importeert: afbeeldingen, lettertypen en geluid.

| Map | Wat hoort erin |
|---|---|
| `sprites/` | Sprites en spritesheets van dorpelingen, vijanden, gebouwen en effecten |
| `tiles/` | Tegelafbeeldingen voor de terrein- en gloom-`TileMapLayer` |
| `fonts/` | Lettertypen voor de interface |
| `audio/` | Geluid en muziek (staat niet in de eerste versie) |

- Commit de `.import`-bestanden die Godot naast elk asset aanmaakt.
- Leg de bron en licentie van **elk** extern asset vast in [`CREDITS.md`](CREDITS.md).
- Gebruik alleen assets met een vrije licentie, bij voorkeur CC0 (zoals Kenney).
- Bestandsnamen in `snake_case`, bijvoorbeeld `villager_worker.png`.
